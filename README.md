# Recruitment Tracker

A [Chickadee Bandit](https://chickadeebandit.com/app-library/recruitment-tracker) app.

Manage rush and recruitment pipeline: add prospects, move them through stages (invited → rushed → bid → pledged), record secret votes and notes.

## Features

- Prospects with stage: invited, rushed, bid, pledged.
- Votes and notes per prospect.
- Adults only.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-recruitment-tracker/releases/latest/download/bundle.json
```
